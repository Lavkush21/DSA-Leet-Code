# LeetCode Contest Strategies ☕🔥 (Java Grind 2025)

**Day 1: November 10, 2025**  
Aaj se shuru kiya LeetCode contests ka proper grind. Yeh strategies top performers se collect ki hain — Knight → Guardian → Grandmaster tak le jaayengi.

## 1. Contest Format & Mindset
- Weekly (har Sunday 8:00 AM IST) & Biweekly (alternate Saturday 8:00 PM IST) — 90 mins, 4 problems.
- Q1 Easy, Q2 Easy-Med, Q3 Med-Hard, Q4 Hard/Math/Niche.
- **Rule:** 90:00 tak ladna hai, kabhi quit mat karna!

## 2. During Contest: Time Management
| Phase      | Time     | Strategy |
|------------|----------|---------|
| 0-5 mins   | Read all 4 | Easiest pehle (Q1 → Q2) |
| 5-40 mins  | Q1 + Q2   | 100% solve, <15 mins total |
| 40-70 mins | Q3        | Rating booster |
| 70-90 mins | Q4/debug  | Stuck 15 mins → skip → wapas |

**Tip:** 15-20 mins stuck → partial lock karo → aage badho.

## 3. Preparation Strategy
- **NeetCode 150 + Blind 75** pehle complete karo.
- Daily 1 virtual contest (last 50 weekly/biweekly).
- 5-10 Medium/Hard timer ke saath.
- Patterns: Two Pointers, Sliding Window, DP, Graph, Binary Search, Heap.

## 4. Post-Contest Ritual
- Same day upsolve sab problems.
- Editorial → khud solve → 2-3 similar problems.
- Mistakes note karo (Notion/Excel).
